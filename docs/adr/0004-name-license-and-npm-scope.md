# Name GridCue, license Apache-2.0, npm scope @gridcue

The owner confirmed the working name GridCue, the Apache-2.0 license for its explicit patent grant, and `@gridcue` as the npm scope. As of 2026-09-23 neither `gridcue` nor `@gridcue/core` was taken on npm. The `@gridcue` npm org should be claimed before the first publish. Trademark and domain checks are still to be redone right before public launch.
