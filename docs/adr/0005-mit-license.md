# MIT license instead of Apache-2.0

The owner chose MIT over the Apache-2.0 license recorded in ADR 0004. MIT is the norm for React, shadcn, and TanStack ecosystem libraries, which is where GridCue's adopters come from. The trade-off is that MIT carries no explicit patent grant. The name GridCue and the `@gridcue` npm scope from ADR 0004 still stand.
